# Foundry Discovery Intake — Zero-New-Spend Operating Procedure

Status: **prepared, NOT a verified private inbound channel**. No customer contact, external outreach, payments, new address, backend or automations activated.

## Universal intake process

The same discovery sequence applies across automotive, HVAC, plumbing/electrical, landscaping, cleaning and other service businesses:

1. **Find interest:** business sees honest research-stage industry page or reaches out through an independently agreed private contact method.
2. **Permission-aware response:** a human confirms that the business wants a conversation; no unsolicited automation.
3. **15-minute intake:** ask the type of business, current process, rough workload, biggest repetitive task, existing constraints and definition of success. Do not request their customers' information.
4. **Anonymized summary (private):** record industry, workflow category, estimated weekly volume (clearly unverified), current workflow, success measure, constraints and next agreed step.
5. **Fictional walkthrough:** show existing non-live missed-call demo; label other workflows as concepts.
6. **Decision:** assess whether a no-message manual pilot is useful or whether actual provider operations would be essential. No live service before independent release review.

## Private channel status

An existing connected Gmail account was discoverable, but its name is not verified as an approved Foundry business-contact identity. Publishing that account on the site would expose an address the owner has **not explicitly approved for advertising**. Therefore the static site retains a truthful statement that no dedicated Foundry mailbox is published. A mailbox address and owner approval are required before an `mailto:` call to action can safely be added.

When a designated business mailbox has been approved, implement a carefully escaped `mailto:` link to that address; do not create a public web form without authenticated secure server-side handling, privacy/retention review and spam controls. A `mailto:` link opens the visitor's local mail client; it is not a guaranteed delivery channel or a hosted form.

## Required controls

Store any real lead identity only in an access-controlled private system. Don't post names, phone numbers, emails, appointments, client records or confidential notes to GitHub issues, commit history, Pages or CI artifacts. No automatic promotional messaging or bulk outreach; reviewed customer-facing copy must distinguish research, offline demonstrations and available service.
