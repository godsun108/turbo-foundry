# Foundry Autopilot demo script

**Opening:** “A missed call can be a missed opportunity. Foundry Autopilot is being built to help businesses follow up on eligible calls, with consent and opt-out protections.”

**Show:** Run `python -m src.autopilot.demo`. Explain five fictional events: two eligible calls, one duplicate, one lacking consent, and one opted out.

**Explain:** “The demo simulates two follow-up messages and blocks three events. No texts were sent and no customers were recovered.”

**Ask:** “How many inbound calls do you miss each week? How do you follow up today? Do you already collect consent for SMS? Which phone and scheduling systems do you use?”

**Close:** “We're looking for a design partner to validate the workflow and metrics. A real pilot would only start after the provider integration, safeguards, and authorization are ready.”

Do not present simulated results as customer testimonials, revenue, or production performance.
