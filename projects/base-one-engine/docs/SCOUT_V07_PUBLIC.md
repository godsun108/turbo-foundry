# Scout v0.7 — Public-Data Production Path

Scout now has a credential-free scheduled path using the St. Lucie County Property Appraiser public ArcGIS service.

Daily output:
- public-scout.json
- public-scout.csv
- NOTICE.txt

The output is deliberately labeled **public-record candidates**, not listings. Appraised, assessed, taxable, and historical-sale values must never be presented as current asking prices.

This path requires no RentCast key and no MLS credentials. It is useful for parcel discovery, research, enrichment, and building a watch universe while active-listing access remains dormant.
