# Deal Report v0.1

The Deal Report is the standardized output layer for Base One Engine.

It combines:

1. normalized property facts,
2. source provenance,
3. explicit analytical assumptions,
4. missing-data checks,
5. financing scenario calculations,
6. stress-test results, and
7. a deterministic intake fingerprint.

## Missing-data policy

Base One withholds scenario calculations when required analytical inputs are absent. It does not replace unknown taxes, insurance, rent, or rehab with hidden defaults.

## Decision policy

The report does not emit a buy/sell verdict or hide tradeoffs behind a composite score. Users can compare the reported economics and risks against their own objectives and constraints.
