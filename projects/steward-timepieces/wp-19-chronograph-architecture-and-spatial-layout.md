## 1. Purpose and scope

WP-19 connects the chronograph gear-train candidate work to the existing C-01 spatial datum and display-layout studies. It provides a geometry-checking tool for explicit candidate gear centers, component envelopes and axial intervals.

It is not a CAD assembly, a dimensioned movement, a selected chronograph architecture, or proof of physical fit. No case diameter, movement diameter, movement height, gear module, tooth count, shaft coordinate, plate thickness, tolerance or component envelope is selected by this work package.

No preferred option is silently promoted to a selected design.

## 3. Coordinate and datum policy

Use the existing dial-side orthographic convention:
- origin O at movement/dial center;
- +X toward 3 o'clock;
- +Y toward 12 o'clock;
- coordinates in millimetres only after a controlled reference dimension is available;
- normalized dial coordinates x/R and y/R may be converted only using a supplied opening radius R.

All Z intervals must reference the same approved axial datum. Layer names describe functional packaging zones; they do not excuse interference when actual Z intervals overlap.

Each geometry input must include:
- component or mesh identifier;
- numeric dimensions and units;
- evidence class (measured, calculated, supplier-confirmed, provisional or TBD);
- source drawing/model and revision;
- owner and review status in the controlled layout register.

The executable helper accepts dimensions but does not yet enforce a full evidence/source register; the controlled drawing package must carry that traceability.

## 4. Gear mesh geometry

For a standard external spur-gear pair with common module m and tooth counts z1 and z2:

[
r_1=\frac{mz_1}{2},\qquad r_2=\frac{mz_2}{2}
]

[
a_{nominal}=r_1+r_2=\frac{m(z_1+z_2)}{2}
]

For supplied shaft-center coordinates:

[
a_{actual}=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}
]

[
\Delta a=a_{actual}-a_{nominal}
]

The tool compares the absolute center-distance deviation with an explicitly supplied tolerance. That tolerance is a user input and is not generated by the tool.

This calculation is only preliminary pitch geometry. It does not evaluate involute tooth profiles, pressure angle, profile shift, backlash, contact ratio, undercut, tooth strength, lubrication, runout, bearing play or manufacturing process capability.

## 5. Component envelope and axial clearance

For each simplified circular XY envelope, the tool calculates center separation d and planar clearance:

[
c=d-(r_A+r_B)
]

A pair is checked when its supplied closed Z intervals overlap by a positive amount. Negative planar clearance flags overlapping simplified envelopes; zero is tangency. Pairs with no Z overlap are not flagged as collisions by this simplified model.

The model deliberately uses circular envelopes as reservations. Actual gear profiles, levers, springs, rotor sweeps, hands, calendar discs and moving parts require exact or swept geometry in CAD. Dynamic movement, deflection, tolerances, endshake and assembly paths are not covered.

## 6. Dial-to-movement integration

The display study remains at normalized coordinates until the dial opening is established. WP-19 supplies a helper to convert a normalized point to millimetres using an explicit opening radius.

For each dial concept, the later integrated layout must reserve complete envelopes, not just centers:
- central hour/minute/chronograph hand stack;
- central seconds arbor and hand sweep;
- running-seconds register;
- 30-minute and 12-hour register axes, hands and scales;
- weekday/date apertures and rotating discs;
- calendar drive and jumper clearance;
- crown, stem and pusher interfaces;
- rotor sweep, balance access and caseback clearance.

No dial concept is selected here. A, B and C must be compared against actual register dimensions, calendar-disc geometry, movement architecture, readability and service access.

## 7. Power-path architecture interfaces

The two power-path candidates remain:
- **P1 — fourth-wheel/seconds-arbor take-off:** potentially direct 1 rpm chronograph source, subject to torque margin and rate disturbance evidence.
- **P2 — dedicated chronograph drive:** permits deliberate drive design and possible load isolation, subject to extra meshes, losses, packaging and service complexity.

For each candidate, a layout drawing must identify the source arbor, clutch interface, central seconds drive, counter take-offs, brake, control components and reset interfaces. A line on a functional diagram is not a physical shaft or a selected gear.

## 8. Executable model

Files:
- `tools/c01_layout_geometry.py`
- `tools/test_c01_layout_geometry.py`

Functions:
- gear pitch radius from supplied integer tooth count and module;
- external mesh nominal center distance and actual-center deviation;
- comparison against a supplied center-distance tolerance;
- simplified circular component-envelope clearance for overlapping axial intervals;
- normalized dial coordinate conversion using a supplied opening radius;
- integrated evaluation response that explicitly states fit is not certified.

### Verification command

From `projects/steward-timepieces/tools`:

```bash
python -m unittest test_c01_layout_geometry.py
```

Unit-test values are synthetic arithmetic fixtures only. They are not C-01 dimensions, tooth counts, module or clearances.

## 10. Required downstream CAD and engineering checks

Before a candidate is accepted:
- define movement and case envelope from controlled case requirements;
- select the dial concept through a documented trade study;
- obtain source-wheel speed and torque evidence;
- define the actual tooth system and evaluate undercut/contact ratio/strength;
- place all arbor axes and validate center distances and mesh directions;
- check profile interference, backlash, endshake, pivot and bearing geometry;
- check plates, bridges, screws, rotor, balance, calendar discs and chronograph controls;
- model swept volumes for levers, hammers, springs, hands and rotor;
- establish tolerance stack, deflection and shock clearances;
- demonstrate assembly/disassembly and service access;
- review chronograph load and rate impact under matched stopped/running tests.
