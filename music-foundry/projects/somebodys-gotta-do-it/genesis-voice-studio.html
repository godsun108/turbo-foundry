Kokoro Vocal Studio

Local-in-browser neural speech synthesis. Select a model file stored on your device, choose a voice, generate a spoken take, then download its WAV for the vocal timeline.

1 · Load a voice model

No model is bundled or downloaded automatically. For Kokoro, the documented GPU bundle is about 295 MB; the CPU-compatible bundle has a larger memory footprint. Choose a model that matches the selected compute mode. Model source and files.

2 · Create spoken or sung performances

3 · Sing from a MIDI-aligned lyric score

Reuse the loaded Kokoro voice as the singer. Import a Music Foundry vocal-score JSON with placed syllables, MIDI pitches, onsets, durations, and tempo. The browser synthesizes each syllable locally, retunes its voiced vowel with PSOLA, and assembles the notes on the score timeline.

No user recording or reference singer is needed. This is score-conditioned melodic TTS: the existing neural speech voice supplies the timbre, and local pitch-synchronous DSP creates the sung notes. It is a practical first singing renderer, not a separately trained human singing model. Unplaced scaffold scores are rejected rather than guessed.

4 · Preview and export

Ready. Choose a local model file to begin.

Export is 48 kHz, mono, 16-bit PCM WAV. Spoken mode is neural TTS. Sung mode reuses the same local TTS voice and retunes score-aligned syllables. No voice cloning is performed. Audio and text are processed in this browser worker; the model/runtime files are loaded locally or from the pinned open-source runtime CDN.

Privacy and compatibility: the selected model is not uploaded by this page. The JavaScript runtime and WebAssembly files are fetched from jsDelivr at a pinned version. iPhone Safari/WebGPU performance and model memory use still require device testing. If GPU initialization fails, try a CPU-compatible model and CPU mode.
