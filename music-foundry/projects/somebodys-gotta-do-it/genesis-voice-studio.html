Kokoro Vocal Studio

On-device neural vocal generation. Install the voice model once, choose a voice, create spoken takes or score-conditioned sung takes, then audition and export WAV files into the vocal timeline.

Quick start

One tap loads the approved draft score, initializes the on-device singer if needed, and starts the vocal render. First use downloads the model.

1 · Load a voice model

The studio downloads the Apache-2.0 Kokoro model directly from its published Hugging Face release and runs inference on this device. The first install is about 295 MB. The model is cached by this browser when storage permits; no model upload or voice recording is involved.

The GPU bundle pairs the acoustic model on CPU with a GPU vocoder. The CPU-compatible bundle uses more memory. The model is downloaded directly from its published release; installation and inference stay on this device. Model source and files.

2 · Create spoken or sung performances

The button loads the lyric lines from the project cue sheet, leaving out production notes. Generate a full spoken-led vocal pass, then download the WAV and place it on the vocal timeline.

3 · Sing from a MIDI-aligned lyric score

Reuse the loaded Kokoro voice as the singer. Import a Music Foundry vocal-score JSON with placed syllables, MIDI pitches, onsets, durations, and tempo. The browser synthesizes each syllable locally, retunes its voiced vowel with PSOLA, and assembles the notes on the score timeline.

No user recording or reference singer is needed. This is score-conditioned melodic TTS: the existing neural speech voice supplies the timbre, and local pitch-synchronous DSP creates the sung notes. It is a practical first singing renderer, not a separately trained human singing model. The bundled Fine China score is a composition draft and still needs listening and human approval. Unplaced scaffold scores are rejected rather than guessed.

4 · Preview and export

Ready. Install the Kokoro model to begin.

5 · Combine the sung take with Fine China

This uploads only the WAV you just generated to your authenticated private Music Foundry job. The server aligns the score's beat offsets and creates a combined preview mix.

Export is 48 kHz, mono, 16-bit PCM WAV. Spoken mode is neural TTS. Sung mode reuses the same local TTS voice and retunes score-aligned syllables. No voice cloning is performed. Audio and text are processed in this browser worker; the model/runtime files are loaded locally or from the pinned open-source runtime CDN.

Privacy and compatibility: the model is fetched from the published Apache-2.0 release and used locally; it is not uploaded by this page. The app shell, runtime, and model are cached where browser storage permits, but iOS may evict large caches. The first install requires network access. iPhone Safari/WebGPU performance and memory use still need device validation. If GPU initialization fails, choose the CPU-compatible model.
