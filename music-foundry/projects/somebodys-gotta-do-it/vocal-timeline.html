TURBO MUSIC FOUNDRY · EDITOR PREVIEW

VOCAL TIMELINE

Arrange recorded spoken takes against the 127 BPM project grid. Everything stays in this browser session.

1 · Load your session

Start with spoken-takes.example.json or a manifest exported by the recording booth. Select the corresponding WAV files too. Matching uses each file's name; no uploads occur.

Waiting for a manifest and WAV takes.

2 · Arrange the takes

Drag a clip horizontally to change its start time. Tap a clip to edit its layer, offset, gain and pan below. Timeline scale: 50 pixels per second.

PER-TAKE EFFECTS
PHRASE PERFORMANCE · CHOPS / REVERSE / DROP

Select a phrase within this take. Repeat inserts copies after it; reverse flips the selected phrase. Optional drop trigger fires one extra phrase repeat at the first chorus drop (bar 17).

No phrase edit on selected take.
AUTOMATION · TAKE-RELATIVE TIME

Add keyframes relative to the start of the selected take. Supported lanes: gain, filter, delay wet and delay feedback. Values ramp between points.

LOOP LAB · TEMPO-SYNCED A/B

Set two timeline regions. Snap their boundaries to the 127 BPM beat grid, loop A or B, or compare A then B. Repeat count applies to each selected region.

A/B loop regions ready · 127 BPM.
TAKE A/B · QUICK PERFORMANCE COMPARISON

Choose two recorded takes. Compare them over loop region A, or switch instantly between A and B. Both auditions retain their own effects and automation.

Load a manifest and matching WAV files to compare performances.

3 · Preview and export

Render uses browser OfflineAudioContext. Exports a stereo 48 kHz / 16-bit WAV mix and one WAV stem per populated layer, plus the edited JSON manifest. Exported files are separate downloads.

Spoken-take editor only. This does not synthesize speech or singing. The separate sung-vocal workflow remains a future renderer. Download your exports before leaving; this prototype does not persist session data.
