TURBO MUSIC FOUNDRY · EDITOR PREVIEW

VOCAL TIMELINE

Arrange recorded spoken takes against the 127 BPM project grid. Everything stays in this browser session.

1 · Load your session

Start with spoken-takes.example.json or a manifest exported by the recording booth. Select the corresponding WAV files too. Matching uses each file's name; no uploads occur.

Waiting for a manifest and WAV takes.

2 · Arrange the takes

Drag a clip horizontally to change its start time. Tap a clip to edit its layer, offset, gain and pan below. Timeline scale: 50 pixels per second.

3 · Preview and export

Render uses browser OfflineAudioContext. Exports a stereo 48 kHz / 16-bit WAV mix and one WAV stem per populated layer, plus the edited JSON manifest. Exported files are separate downloads.

Spoken-take editor only. This does not synthesize speech or singing. The separate sung-vocal workflow remains a future renderer. Download your exports before leaving; this prototype does not persist session data.
